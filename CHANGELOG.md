# Changelog

## 1.0.0 (2026-11-17)

- Per-spec Pawn scale for AutoGear (`/agr scale`), with Use Pawn turned on once at first login.
- AutoGear upgrades are written into the ItemRack sets that held the replaced item: main sets of the active spec, or the sets you list.
- AutoGear pauses while a situational ItemRack set is worn and during spec switches.
- Works with ItemRack Universal and ItemRack (Forever).
